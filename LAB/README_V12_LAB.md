# LOVENTRE ENGINE — LAB V12
### Sandbox locale per esplorazione curvature + entropia

## 🎯 Scopo
Il LAB V12 implementa una pipeline **isolare**, **sicura** e **non core** per:
- Calcolare metriche grezze
- Calcolare potenziale informazionale
- Classificare lo stato (bus)
- Applicare policy locali
- Derivare una decisione locale
- Produrre un colore e uno score di bridge

Tutto è confinato nella cartella `LAB/` e non modifica **in alcun modo**
il motore principale (attualmente V6).

## 🧩 File principali
- `loventre_lab_metrics_v12.py` — estrazione feature locali
- `loventre_lab_potential_v12.py` — potenziale U = ακ + βH
- `loventre_lab_pipeline_v12.py` — unione metrics+potential
- `loventre_lab_bus_v12.py` — classificazione (SAFE-ish, P_ACC-ish, BLACKHOLE-ish)
- `loventre_lab_policy_v12.py` — suggerimenti locali
- `loventre_lab_decision_v12.py` — decisione finale
- `loventre_lab_bridge_v12.py` — colore + score
- `loventre_lab_entrypoint_v12.py` — demo end-to-end
